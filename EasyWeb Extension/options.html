Configurações da extensão

Perfil global de acessibilidade

Este é o padrão aplicado automaticamente em todos os sites, exceto onde as configurações manuais estiverem ativadas.

Modo de funcionamento

Escolha como o EasyWeb processa os sites neste navegador.

Perfil ativo

O popup só substitui este perfil quando as configurações manuais forem ativadas para um site.

Filtro para daltonismo

Quando ativo, ele substitui o filtro local e o filtro do perfil em todos os sites.

Conexão com a API

Endereço padrão: https://easyweb.api.raemi.xyz.

Snapshots para análise de IA

Os snapshots ajudarão a IA a analisar a estrutura e melhorar a manipulação de acessibilidade de cada site.

Regras de segurança

O mapeamento envia HTML estrutural sem textos ou atributos pessoais e CSS sanitizado, além de metadados de scripts. Cookies, valores de formulários, URLs completas de assets, senhas, campos sensíveis e corpos de scripts são removidos antes do envio.

Experiência Adaptativa

Permite receber planos de IA validados pela API e compilados localmente em CSS seguro pelo EasyWeb.

Como as adaptações são aplicadas

A IA recebe snapshots estruturais autorizados e devolve intenções limitadas. A extensão valida o plano, gera seu próprio CSS e armazena o cache somente neste navegador. Pedidos pessoais não são salvos no MySQL.
